# Math_Game
English: This program is designed to improve math skills. Players can choose the level and the operation, like addition or subtraction, and learn in a playful way.

Deutsch: Dieses Programm soll den Umgang mit Mathematik verbessern. Die Spieler können das Level und die Rechenart, wie z. B. Addieren oder Subtrahieren, frei wählen und spielerisch lernen.
