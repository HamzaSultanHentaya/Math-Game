# Math Learning Game 🎯

A simple and fun C++ console game to practice math skills — choose your level and operation and learn while playing!

Ein einfaches und unterhaltsames C++-Konsolenspiel zum Üben von Mathematikkenntnissen — wähle deinen Schwierigkeitsgrad und die Rechenart und lerne spielerisch!

---

# Project Description / Projektbeschreibung

## English 🇬🇧

This program is designed to improve math skills.  
Players can choose the difficulty level and the type of operation, such as addition or subtraction, and learn in a playful and interactive way.

---

## Deutsch 🇩🇪

Dieses Programm wurde entwickelt, um mathematische Fähigkeiten zu verbessern.  
Die Spieler können den Schwierigkeitsgrad und die Art der Rechenoperation wählen, wie zum Beispiel Addition oder Subtraktion, und auf spielerische Weise lernen.

---

# Instructions / Anleitung

## English 🇬🇧

- Either copy the source code and run it in the console using C++ in Visual Studio  
- Or download the project as a ZIP file, extract it, and open it with Visual Studio

> Important:
> - Visual Studio must be installed on your device to open the full project directly.
> - Alternatively, you can open and run the C++ source files (`.cpp`) using any other C++ compatible IDE or editor, such as Code::Blocks, CLion, Dev-C++, or Visual Studio Code (with the C++ extension).
> - In other IDEs, you may need to create a new project and add the source files manually.

---

## Deutsch 🇩🇪

- Entweder den Quellcode kopieren und in der Konsole mit C++ in Visual Studio ausführen  
- Oder das Projekt als ZIP-Datei herunterladen, entpacken und mit Visual Studio öffnen

> Wichtig:
> - Visual Studio muss auf deinem Gerät installiert sein, um das vollständige Projekt direkt öffnen zu können.
> - Alternativ kannst du die C++-Quelldateien (`.cpp`) auch mit einer anderen C++-fähigen IDE oder einem Editor öffnen und ausführen, wie zum Beispiel Code::Blocks, CLion, Dev-C++ oder Visual Studio Code (mit C++-Erweiterung).
> - In anderen IDEs musst du möglicherweise ein neues Projekt erstellen und die Quelldateien manuell hinzufügen.
